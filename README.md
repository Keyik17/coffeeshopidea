# Roundtrip

A landing page for Roundtrip, an idea for neighborhood cafés: guests sign in to the shop's Wi-Fi with a phone number, and the shop sends a few well-timed offers a month to bring them back.

Live: [roundtrip-landing.pages.dev](https://roundtrip-landing.pages.dev)

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # static site in dist/
```

Built with plain HTML, CSS and JavaScript, bundled with Vite.
